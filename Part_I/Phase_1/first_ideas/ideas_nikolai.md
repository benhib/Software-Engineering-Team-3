# My Ideas for the project
## Custom Learning AI Harness
Create a custom AI harness that enforces best practices for learning new things and uses optimal methodology for learning. It should also give purpose-built tools for agents to create documents that help with studying.

## Shared Learning Platform 
Students and also lecturers can exchange digital documents on an online platform. This makes it possible to avoid redundant work, for example by sharing flashcards, formula collections and exercises. Especially with AI, even more redundant work will be made. So funneling and making sharing easier.
